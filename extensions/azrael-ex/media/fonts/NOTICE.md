# Bundled fonts

## Cascadia Mono

Copyright (c) 2019 - Present, Microsoft Corporation.

The upright and italic variable WOFF2 files are copied unchanged from the
official Cascadia Code v2407.24 release. They use the SIL Open Font License 1.1;
the full license, including its reserved font name, is retained in
`CASCADIA-LICENSE.txt`. `cascadia-provenance.json` pins the release archive,
member paths, unchanged file hashes and font metadata.

Windows prefers the user's installed Consolas, with bundled Cascadia Mono as
fallback. Other desktop platforms default to bundled Cascadia Mono. Consolas
is resolved from installed system fonts and is not redistributed.

## Gyeonggi Millennium Title Light and Batang

Copyright holder: Gyeonggi Province (경기도청).

The Title Light, Batang Regular and Batang Bold WOFF files are copied unchanged
from the official webfont archive.
Source and use conditions: [Gyeonggi Province font page](https://www.gg.go.kr/contents/contents.do?ciIdx=679&menuId=2457).

The official conditions allow free use across media and inclusion and distribution
within programs. Selling or transferring the font itself for payment is prohibited.
These fonts are governed by those conditions, rather than the project's MIT license.
`provenance.json` identifies the download and unchanged file hashes.

Gyeonggi Millennium Title Light supplies Korean text. The Batang files remain
retained assets and are unused by the current font selection.
