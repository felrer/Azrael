두 커서

3.0 / 12.8s

실제 화면 캡처가 아닌 커서 동작 시안입니다. 흰색은 사용자, 파란색 #38BDF8은 모델입니다. 클릭 시 눌림, 드래그 점, 180ms 이전 위치 잔상, 32% 불투명도 대기를 보여 줍니다.

현재 Window Use와 별도 virtual_input / switched 프로토타입의 지원 범위는 다릅니다. 이 시안은 독립 입력이나 사용자 작업 비간섭을 보장하지 않습니다.

모션 줄이기 설정에서는 멈춘 상태로 시작합니다. 상태 버튼과 시간 막대로 움직임 없이 확인할 수 있습니다.
