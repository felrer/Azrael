# Retired Window Use stages

This is user-requested historical source, not a runnable product or a disposable test artifact. Active Window Use behavior is owned by [the current contract](../../docs/architecture/window-use.md).

- `exclusive/` contains retired Windows child-session and Computer Use/Sky control sources, instructions and tests at their former relative paths.
- `shared-snapshots/` preserves pre-change bytes of owners that also implement retained observation, app permissions, Node REPL, settings or packaging. Their active replacements remain at the original paths.
- `manifest.json` records origin, archived path, size and SHA-256. Archived instructions are historical evidence and must not be installed or supplied as active guidance.

The archive is excluded from active runtime payloads and test registration. It does not contain an installed application backup and does not authorize terminating existing Windows sessions. Same-volume archival does not reclaim disk space.

Generic Node REPL and shared approval-card infrastructure remain active. Historical internal `computer-use` names in those retained owners do not expose desktop input or generate a Computer Use skill. Retired mixed stage-authority tests are replaced by app-permission host/MCP checks, runtime packaging checks and transactional skill-retirement checks under the active feature inventory.
