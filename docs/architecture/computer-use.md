# Retired Computer Use

Status: `target` ? Computer Use/Sky desktop input is retired from the next Window Use package. Installed versions retain their state until an explicit update.

The active product contract is [Window Use](window-use.md). The historical desktop implementation and pre-change design are retained in the [source archive](../../archive/window-use-stages-v1/README.md), not active tool guidance.

Generic Node REPL support remains available for other tools. Historical computer-use package directory/helper names do not grant desktop input or install a Computer Use skill. Packaging retains Node and non-Sky services while omitting Sky control and child-session code. Existing selected-window tool ceilings remain native-engine responsibilities under the active Window Use contract.
