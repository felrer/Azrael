# Window Use documentation

<!-- architecture: {"id":"arch.window-use.visualization","feature":"window-use","layers":["ui","host"]} -->

The active [Window Use contract](README.md) owns app-based permissions, masked desktop capture and conversation-only desktop authority. Its [input modes](README.md#input-modes-and-virtualization-boundaries) distinguish selected-window semantic control, shared-foreground collaboration and whole-screen coordinate input. [Multi-pointer collaboration](../multi-pointer/README.md) owns logical user/model cursors, gesture scheduling and cursor presentation. Numbered-stage walkthroughs do not define active permissions or execution guidance.
