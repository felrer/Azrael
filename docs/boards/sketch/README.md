# 스케치 보드

상태: `partial` — Excalidraw 편집기로 그림·화면 캡처에 요구사항을 표시하고 전달하는 로컬 보드다.
Windows Chrome에서 파일 저장·복구·전달과 밝은/어두운 화면을 확인했으며 Linux/macOS는 미검증이다.

Node.js 22 이상이 필요하다. 최초 준비는 인터넷에서 버전이 고정된 패키지를 설치하고 정적 파일을 빌드한다.
프로젝트 루트에서 실행한다.

```powershell
npm ci --prefix docs/boards/sketch
npm run build --prefix docs/boards/sketch
node docs/boards/server.mjs --board sketch --port 4319
```

터미널의 주소를 브라우저에서 연다. 기본 사용 주소는 `http://127.0.0.1:4319/`이고 종료는 Ctrl+C다.
최초 준비 후 실행에는 인터넷과 추가 빌드가 필요 없다. UI 코드를 수정하면 다시 빌드하고 서버를 재시작한다.
패키지에 포함된 글꼴의 CDN 대체 주소는 보안 정책으로 차단한다. 브라우저 도구에 차단된 대체 주소가 표시될 수 있으며
실제 화면과 PNG는 로컬 글꼴을 사용한다.
편집기는 Excalidraw 0.18.1을 재사용하며 엔진을 포크하거나 기능 코드를 제거한 구성은 아니다.

글자·도형·화살표·자유 그리기로 의견을 표시한다. 이미지를 붙여넣거나 **이미지 추가**로 화면 캡처·지도를 넣는다.
도형 하나를 선택하면 분류와 메모를 연결할 수 있다. 색상과 배치만으로 분류나 요구사항을 결정하지 않는다.
일반적인 그리기·실행 취소·다시 실행·이동·확대/축소는 편집기 도구를 사용한다.
단순한 메뉴 구성을 위해 온라인 공유·라이브러리·중복 파일 저장 UI를 제공하지 않는다.

**저장 → 도형 선택 → 전달** 순서로 사용한다. 선택이 없으면 전체 그림을 전달한다.
연결된 글자·화살표 끝점·프레임 내용은 다시 편집할 수 있도록 함께 포함된다.
전달 폴더에 `result.json`, `result.md`, `scene.excalidraw`, `preview.png`, 보드 양식·해석 지침·영수증을 보관한다.
화면의 Markdown 경로를 이 대화에 보내면 에이전트가 관련 그림과 메모·지침을 함께 읽을 수 있다.
저장만으로 대화에 전송되거나 작업이 시작되지는 않는다.

기본 자료는 프로젝트의 `artifacts/board-data/sketch/`에 저장한다. 저장 설정은
`artifacts/board-storage/sketch.json`에 보관한다. **설정**에서 위치와 백업을 관리한다.
위치 변경은 그 폴더의 그림을 불러오며 기존 파일을 이동하지 않는다. 수동 저장과 복원 전에 기존 원본을 백업한다.
저장 충돌·입력 오류·파일 작업 실패 시 편집본을 유지한다. 최신 자료를 불러올 때 저장하지 않은 변경의 폐기를 확인한다.

지원 입력은 PNG·JPEG·WebP이며 개별 4 MiB, 이미지 합계 8 MiB, 최대 100개다.
그림은 최대 2000개 요소와 JSON 16 MiB, 요청은 32 MiB로 제한한다. PNG 미리보기는 4 MiB 이하다.
외부 웹 임베드·링크·SVG 이미지와 온라인 협업은 지원하지 않는다. 복잡한 외부 그림을 붙이면 저장 시 검증 오류가 날 수 있다.
미리보기 생성에 실패하면 편집본을 유지한 상태에서 원인을 표시한다.

코드·글꼴은 `artifacts/boards/sketch/<입력해시>/public/`에 생성하고 `current.json`이 완료된 번들을 선택한다.
서버 시작 시 해당 경로를 고정한다. 빌드 출처·파일 크기·해시는 같은 빌드의 영수증에 남는다.
이 정적 번들은 실행 입력이며 사용자 그림과 구분한다. 설치된 의존성은 무시된 `sketch/node_modules/`에 둔다.
서비스 UI의 숨김은 번들 크기 감소를 보장하지 않는다. 실행 무게의 측정 조건과 결과는 작업 계획에 기록한다.

로그와 오류 진단은 [공통 보드 계약](../README.md)을 따른다. 선택한 데이터 폴더의 `board.log`에
UTC 시각·요청 id·이벤트·오류 코드를 기록하며 그림·메모·파일 본문은 기록하지 않는다.
로그는 2 MiB에서 추가 기록을 멈춘다. 필요한 로그를 보관한 뒤 파일을 이동하면 다음 요청에서 새 로그를 만든다.

대상은 Windows x64·Linux x64·macOS ARM64의 로컬 Node/브라우저다. 이번 수용 검증은 Windows/Chrome에 한정한다.
Azrael에 내장하거나 사용자 확장을 설치하는 작업과 원격 제공은 범위 밖이다.

검사는 프로젝트 루트에서 실행한다. 브라우저 검사는 위의 정적 빌드와 Chrome이 필요하며
`BOARD_CHROME_PATH`로 실행 파일을 지정한다.

```powershell
node --test docs/boards/tests/boards.test.mjs docs/boards/tests/sketch.test.mjs
node docs/boards/tests/sketch-render.mjs
```

검사 fixture는 `artifacts/verification/board-sketch-*`, 결과·측정·화면은 `artifacts/logs/board-sketch/`에 보관한다.
완료 fixture는 프로젝트의 guarded cleanup 스크립트로 정리한다. 사용자 그림과 실행 중인 정적 번들은 유지한다.
이미지와 기본 편집기·폰트의 라이선스는 각 소유자의 조건을 따른다. 패키지 MIT 라이선스 및 포함 자산의 고지를 정적 빌드에 함께 보관한다.
