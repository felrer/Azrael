# 요구사항 보드 프로토타입

상태: `partial` — 로컬 웹앱으로 기본 입력·분류·공간 배치·파일 저장·백업·결과 전달을 제공한다. Windows Chrome에서 수용했으며 Linux/macOS 실행은 미검증이다.

프로젝트 루트에서 Node.js 22 이상으로 실행한다. 외부 패키지 설치나 Azrael 빌드는 필요 없다.

```powershell
node docs/boards/server.mjs
```

터미널에 표시된 로컬 주소를 브라우저에서 연다. 종료는 실행한 터미널에서 Ctrl+C다.
기본 주소는 `http://127.0.0.1:4318/`이며 `--port 4320`으로 변경할 수 있다.

항목을 추가해 제목·분류·양식 필드·메모를 입력한다. 목록과 map은 같은 항목을 편집한다.
map에서 항목을 끌거나 위치·크기를 입력해 배치한다. 분류를 추가·수정하고 필터로 표시 범위를 좁힐 수 있다.
프로토타입의 제한은 항목 500개, 분류 100개, HTTP 요청 2 MiB다. 큰 이미지·첨부 자료는 저장하지 않는다.

저장은 사용자가 누른 시점에 수행한다. 저장 상태와 전달 결과 생성 상태는 별도로 표시한다.
양식 필드의 기본값과 사용자가 직접 지정한 값은 화면과 전달 데이터에서 구분한다.
원본이 존재하면 저장 전에 자동 백업하고, 수동 백업과 복원을 제공한다. 백업 자동 삭제는 하지 않는다.
복원 시 현재 원본을 먼저 백업하고 저장 버전은 증가한다. 저장 실패·다른 화면의 변경 충돌은 편집본을 유지한다.

기본 데이터는 프로젝트의 무시된 `artifacts/board-data/prototype/`에 저장한다.
화면의 저장 설정에서 다른 절대 경로를 지정할 수 있다. 위치 변경은 그곳의 자료를 불러오며 기존 자료를 옮기지 않는다.
실행 시 `--data-root <절대 경로>`로 저장 위치를 지정하면 화면에서 바꾼 설정과 별개로 해당 위치를 사용한다.

저장 후 전달할 항목을 선택해 결과 미리보기를 확인하고 **결과 만들기**를 누른다.
저장된 해당 버전의 JSON·Markdown·보드 양식·해석 지침이 하나의 전달 폴더에 보관된다.
생성된 Markdown 경로를 이 대화에 전달하면 에이전트가 관련 결과를 읽을 수 있다.
프로토타입은 대화에 자동으로 파일을 첨부하거나 작업을 시작하지 않는다.

코드는 [공통 보드 계약](../README.md)을 따른다. `board.json`은 양식,
`rules.md`는 값의 해석, `board.js`는 이 보드의 화면 조합을 담당한다.
새 보드는 이 작은 폴더를 복사하고 id·양식·지침을 바꿔 시작한다. 서버는 `--board <name>`으로 해당 폴더를 선택한다.

진단은 선택한 데이터 폴더의 `board.log`에 JSON 줄 형식으로 남는다. 시각은 UTC이며 요청 ID로 실패를 연결한다.
입력 본문·메모·경로·인증 토큰은 기록하지 않는다. 파일은 2 MiB에서 기록을 멈추고 터미널에 알린다.
필요한 기록을 따로 보관한 뒤 로그 파일을 이동하면 다음 실행에서 새 로그를 만든다.

대상은 Windows x64·Linux x64·macOS ARM64의 로컬 Node/브라우저 실행이다.
이번 수용 검증은 Windows/Chrome에 한정한다. Azrael 내장·원격 공유·동기화·실제 지리 지도는 제공하지 않는다.

프로젝트 루트에서 회귀 검사를 실행한다. 브라우저 검사는 격리된 Chrome 프로필을 사용하며
`BOARD_CHROME_PATH`로 Chrome 실행 파일을 지정할 수 있다.

```powershell
node --test docs/boards/tests/boards.test.mjs
node docs/boards/tests/render.mjs
```

검사 데이터는 `artifacts/verification/board-prototype-*`에, 결과와 화면은
`artifacts/logs/board-prototype/`에 생성된다. 화면 검사는 빈 전용 fixture에서 실행한다.
완료한 fixture는 프로젝트의 guarded cleanup 스크립트로 정리하며 사용자 `board-data`는 유지한다.
중단 후 `.write.lock`이 남으면 관련 프로세스가 종료됐는지 확인하고 로그와 원본을 보존한 뒤 잠금만 정리한다.
