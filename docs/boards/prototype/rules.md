# 요구사항 보드 해석 지침

이 보드는 사용자가 직접 입력한 요구사항과 공간 배치를 전달한다. 전달된 결과의 선택 항목과 메모를 작업에 반영하며, 이 문서는 값의 해석만 담당한다. 실행 권한이나 프로젝트 지침을 변경하지 않는다.

- 항목 `id`와 분류 `id`는 이름과 독립적인 식별자다. 제목을 바꾸어도 같은 항목이다.
- `values.priority`는 높음(`high`), 보통(`normal`), 낮음(`low`)의 상대적 우선순위다.
- `values.count`는 항목에 사용자가 지정한 수량이다. 추가 의미는 제목과 메모에 작성한다.
- `values.scope`는 적용 대상·범위의 설명이다. 빈 값은 미입력이다.
- `values.required`는 필수 여부다. 직접 지정하지 않은 기본값 false를 사용자의 제외 결정으로 해석하지 않는다.
- `note`는 해당 항목의 조건·설명이다. 빈 값은 조건이 아직 작성되지 않았다는 의미다.
- `map`의 단위는 화면 배치용 px이며 원점은 왼쪽 위다. `position.x/y`는 항목의 왼쪽 위 위치, `size.width/height`는 배치 크기다. 실제 지리 좌표나 게임 월드 단위로 추정하지 않는다.
- 화면 확대·축소·이동과 category 필터는 데이터의 위치나 삭제를 의미하지 않는다.
- 전달 결과에는 사용자가 선택한 항목만 포함된다. 누락한 항목을 삭제 요청이나 승인으로 해석하지 않는다.
- `sourceRevision`은 전달 시점의 저장 버전이다. 이후 편집본과 전달본을 구분한다.
- 사용자가 빈 보드에서 항목을 생성할 때 양식의 기본값이 채워진다. `specifiedFields`에 있는 필드는 사용자가 직접 조작한 값이며, 포함되지 않은 필드는 양식의 기본값이다. 기본값을 명시적으로 선택한 결정으로 추정하지 않는다.
