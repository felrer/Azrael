# 목록·카드 보드의 입력 해석

이 자료는 GrowKick 원본과 연결되지 않은 합성 더미 데이터로 모듈을 시험한 결과다.
사용자가 직접 적은 이름·목록 배정·태그·검토 상태·메모가 명시적 정보다.
폴더는 목록을 묶는 표시 구조이며 게임 단계나 적용 순서, 강도·보상 수치를 의미하지 않는다.
미분류 항목의 listId는 null이다. 폴더 삭제는 목록을 루트로 옮기고, 목록 삭제는 항목을 미분류로 돌린다.
필터로 보이지 않는 항목도 자료와 선택에 남을 수 있다. 전달본의 selectedItemIds가 전달 범위다.
미리보기 그림은 더미 표시이며 실제 게임 모델의 모양·크기·물성을 보증하지 않는다.
저장이나 전달본 생성은 GrowKick·Studio 변경 또는 메모에 적힌 작업의 실행 승인이 아니다.
