#### 승인된 구현 범위 — 적용 완료와 후속 검토

1. **결정 근거와 phase 측정:** 기존 build-metrics/cache receipt에 선택 owner·물리 target·호환 key·profile/toolchain/flags 및 모듈 miss reason·입력별 manifest를 기록한다. input enumeration/hash, output inventory/hash, save/copy, Cargo preparation/compile/link를 분리한다. hit/miss 관측은 테스트 통과 근거가 아니며 실제 exit/unknown 보호는 유지한다.
