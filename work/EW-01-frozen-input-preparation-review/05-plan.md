# 나머지 빌드 단계 검사 정리

## 목표와 권한
사용자는 앞선 소스 검사 이외 단계의 테스트·검사를 한 단계씩 testing 지침에 따라 축소하도록 승인했다. 단순 존재·문구·구현 형태 확인이고 반복 작업 누락 방지 근거가 불분명한 검사는 삭제한다. 자동 검사 대체물을 의무적으로 만들지 않는다. 제품 기능과 소유권·불변 입력·정확한 패키지 신원·기존 설치 보호는 유지한다. Rust/Cargo 네이티브 검증 및 실제 엔진/IPC 검사는 수정·실행하지 않는다. 전체 제품 빌드·설치도 제외한다.

## 단계와 책임
1. 입력·사전 준비: 이미 정리한 capture/snapshot 사례와 121개 source 감사는 재사용한다. 나머지 순서 읽기·환경 준비·작업공간 검사를 조사·축소·확인한다.
2. 제품 조립 도구: PowerShell build/cache/deploy/metrics와 JS incremental 검사를 검토한다.
3. 패키징·보존: 준비·변환·archive 및 검증 checkpoint 테스트와 기존 소스 감사의 중복을 연결해 검토한다.
4. 최종 호스트 검증: JS/PowerShell 검증기 자체의 중복·구조적 검사를 검토하며 실제 native IPC/호환성 검사는 건드리지 않는다.

단계별로 조사·변경·영향 확인을 마친 뒤 다음 단계로 넘어간다. Root가 삭제 판단·공유 계약·통합·검증·정리를 소유한다. 필요한 읽기 조사는 같은 단계의 독립 파일 범위만 위임한다. 공통 테스트 소스가 대상이고 실제 검증은 Windows x64다. 현재 미커밋·동시 변경은 보존한다. 상세 결정·원본 hash·실제 exit·정리는 17-other-stage-retirement.json에 기록한다. 시간 절감은 측정 전 추정하지 않는다.

## 완료 결과

- 입력·사전 준비: 순서 읽기 반복/내부 수치, capture/snapshot 존재·시간·미사용 CLI 검사를 축소했다. 입력 바이트·소유권·재사용과 도구/환경 전달 검사는 유지했다. 기존 capture 13 / snapshot 9 / workspace 16 실행 근거를 재사용하고 수정 파일 문법을 확인했다.
- 제품 조립: TypeScript 중복/존재/컴파일러 설정 검사, PowerShell AST/명령 개수/중복 문법 검사를 제거했다. 실제 증분 컴파일 9개와 격리된 recipe 검사, 게시 순서 assertion이 exit 0이었다.
- 패키징·보존: 앞선 source-suite 결과를 재사용했다. 실제 패키지 신원·원본/복사 후 provenance·해시 검사는 유지했다. verification-state는 Windows IPC 경계여서 제외했다.
- 최종 호스트: 고정 제목·aria-label 문구 검사와 관련 mock 사례를 제거했다. mount 응답·revision·언어 전달·오류 검사는 남았고 14개 source 검사가 exit 0이었다. 실제 설치 호스트/엔진 검증은 실행하지 않았다.

상세한 변경, 유지 사유, 재실행/실패 및 정리 결과와 SHA는 `17-other-stage-retirement.json`에 있다. 신규 일회성 테스트 파일·제품 빌드·설치는 없다. recipe fixture는 기존 테스트 소유자의 finally에서 삭제됐고 실제 부재를 확인했다. 증분 테스트의 force 삭제 옵션을 제거했으며 해당 fixture도 부재다. 다른 임시 파일은 생성하지 않았다. Windows x64 외 환경과 전체 빌드 시간 절감은 미검증이다. 기존/동시 변경과 인덱스를 보존하기 위해 task commit은 만들지 않았다.
