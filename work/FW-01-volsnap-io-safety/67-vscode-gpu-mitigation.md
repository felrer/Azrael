# VS Code GPU 가속 완화 설정

- 사용자 승인: 별도 GPU 시험 프로필 대신 사용자 프로필의 GPU 가속을 끄고 기존 빌드를 재개한다.
- 변경: `C:/Users/felre/.vscode/argv.json`의 기존 주석 한 줄을 활성화하여 `"disable-hardware-acceleration": true`로 설정했다. 다른 설정과 crash reporter 설정은 유지했다.
- 검증: JSONC의 줄 주석을 제외한 JSON 파싱 성공, 해당 값 `true` 확인(actual exit 0). 설치된 VS Code의 `mainImpl.js`가 이 runtime argument를 처리함을 확인했다.
- 적용 한계: 변경 시점의 실행 중인 VS Code는 재시작하지 않았다. 현재 프로세스에 GPU 비활성화가 적용됐거나 크래시 원인이 해결됐다고 주장하지 않는다. 사용자 창을 종료하거나 드라이버·시스템 설정을 바꾸지 않았다.
- 원인 판단: `1a8`·`1b8`는 우선 조사 가설이며 VS Code 종료와 인과관계는 미확정이다. 사용자는 화면 변화와 그래픽 재설정 단축키 사용이 없었다고 답했다.
- 후속: 기존 고정 입력, 명시된 31개 engine feature와 필수 최종 패키지 검증으로 빌드를 재개한다. GPU 시험용 새 프로필은 만들지 않는다. 이미 요청된 격리 Azrael 설치 대상은 유지한다.
- 되돌리기: 사용자가 요청하면 이 단일 키를 이전 주석 상태로 복원한다. 별도 백업 파일은 만들지 않았다.
