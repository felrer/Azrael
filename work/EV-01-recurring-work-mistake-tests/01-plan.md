# 테스트 유지 기준과 일회성 검증 정리

## 목표와 권한

- 사용자는 testing 내부 중복·충돌을 정리하고 일회성 테스트를 포함하여 이해하기 쉬운 구조로 만드는 수정 계획을 요청했다. 사용자가 계획과 직역안을 승인하여 본문 재구성까지 실행했다.
- 앞선 합의는 유지한다: 작업하는 자신을 직접 지칭하며 반복 절차 누락, 수정으로 원인이 제거된 구현·설계 오류, 구체적 후속 편집으로 재발 가능한 오류를 구분한다. 신규·기존 테스트에 같은 유지 기준을 적용한다. 일반 제품 오류는 최소 검증과 빠른 빌드 후 실사용 피드백을 우선한다.
- 범위는 플랫폼 공통 지침이다. 실제 제품 테스트 삭제, 필수 검사 목록 변경, 제품 코드·빌드 변경은 제외한다. Windows에서 문서 및 활성 설치 경로 일관성을 확인한다.

- testing 16/26/33/35/53행에 이번 검증과 영구 유지의 구분 및 유지 기준이 분산되어 있다.
- 22행의 중요도만으로 추가·유지하지 말라는 문구는 일회성 검사 추가까지 억제할 수 있다. 영구 유지 판단에 한정해야 한다.
- 37/39행의 기대값과 경계 검증 규칙은 유지 테스트 절에 있지만 일회성 검사에도 적용되어야 한다.
- 12/22/49/53행에 필수 검사 보존 규칙이 반복된다. 권한 규칙은 한 곳에 두고 플랫폼 절에는 실제 검증 범위 보고만 남긴다.
- 63행의 surviving protection은 55행의 대체 자동 검사 불필요 원칙과 해석상 긴장이 있다.

## 적용한 구조와 변경

1. 목적·권한: 기존 권한, 필수 검사 및 다른 스킬의 소유 범위를 한 곳에 둔다.
2. 이번 작업의 검증 선택: 기존 검사/결과 재사용 → 필요한 최소 일회성 검사 → 실사용 확인 범위를 선택한다. 일회성 검사를 항상 만들도록 요구하지 않는다.
3. 테스트 유지 판단: 세 가지 재발 분류와 비용 판단을 한 곳에 두고 신규/기존 모두 적용한다. 중요도만으로 영구 유지하지 않는다는 범위를 명확히 한다.
4. 공통 작성·실행: 일회성·유지 검사 모두에 기대값, 실제 경계, 최소 mock, 실제 실행/종료 코드, 결과 재사용 조건을 적용한다.
5. 기존 테스트 정리와 수명 종료: 동등 보호를 주장하는 통합과 의도적인 자동 검사 축소를 구분한다. 일회성 소스는 결과 확인/필요 재검증 후 정리하고, 유지 승격은 같은 재발 기준으로 판단한다. 유지 테스트가 만든 로그·fixture 등 실행 산출물은 영구 테스트 소스와 별도로 기존 artifact owner가 관리한다. 활성/진단/사용자 확인에 필요한 자료는 implementation의 기존 절차에 위임한다.
6. 결과 보고: 이번에 확인한 범위, 남긴 테스트와 재발 근거, 제거/축소하거나 실사용에 넘긴 범위, 미검증 사항과 정리 상태를 기록한다. 대체 자동 검사는 있을 때만 기록한다.

## 실행과 검증

- 승인된 직역안에 맞춰 testing 본문을 구조적으로 재작성했다. 같은 규칙을 새 절에 추가하면서 이전 문장을 남기지 않는다.
- implementation/Work/test-cleanup의 기존 링크와 역할을 확인한다. 외부 참조 중인 heading anchor는 유지하거나 호환 anchor를 제공한다. 공통 판단 기준은 testing에만 둔다.
- 설치 경로는 현재 원본 Junction이다. 실제 연결과 바이트 일치를 다시 확인하고 SKILLS-SOURCE의 해당 항목만 갱신한다. 파일 매핑은 변경이 있을 때만 갱신한다.
- 기존 스킬 형식 검사(Python -X utf8), import-instructions --check, diff --check와 변경 범위/참조 검토를 수행한다. 문구 정리용 영구 테스트나 제품 빌드는 추가하지 않는다.
- 대표 상황 검토: 패키징 누락은 기존 빌드 검출 여부 우선, 고친 계산식은 구체적 재발 경로가 없으면 일회성 검증 후 정리, 호환 분기 제거 재발은 최소 유지 검사, 유지 검사의 실행 로그는 별도 수명 관리. 이 검토는 문서 판단 일관성 확인이며 실제 대화 행동 개선 증거로 주장하지 않는다.
- 기존 다른 작업의 변경을 보존하고 승인된 변경만 커밋한다. 임시 자료는 필요가 끝나면 기존 소유 절차로 정리한다.
