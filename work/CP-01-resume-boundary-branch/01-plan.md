# 재개 경계에서 대화 분기

작업 종료와 다음 재개 사이의 안내 줄에 hover 또는 키보드 focus 시 ‘여기서 브랜치’ 버튼을 표시한다. 기존 canonical turn 분기 callback을 재사용해 그 턴까지의 새 대화를 만들며 원본의 후속 실행을 유지한다. Git branch 생성·앱 설치는 요청 범위에 포함하지 않는다.

공통 webview 변경으로 Windows x64·Linux x64·macOS ARM64를 대상으로 한다. Windows에서 소스 회귀 및 light/dark native React/CSS 렌더·마우스·키보드 동작을 검증하며 다른 OS 및 설치 앱은 미검증으로 구분한다.

scripts/inject-deferred-turn.cjs의 native turn scope가 기존 분기 callback을 대기 안내 컴포넌트에 전달하도록 한다. 읽기 전용·지원 host·canonical turn·진행 중 eligibility와 모델 선택은 기존 분기 경로가 소유한다. 컨텍스트로 전달해 turn props와 영속 wait 메타데이터는 바꾸지 않는다.

필수 확인: 경계마다 해당 턴 callback을 사용함, 재개 뒤 내용 제외, 원본 변경 없음, hover/focus 표시, 네이티브 테마와 버튼, deferred 및 일반 분기 회귀. 기존 test-deferred-turn/test-thread-branch와 verify-deferred-turn-render를 확장한다. 기능 보존 목록은 기존 ui.deferred-turn/ui.thread-branch를 연결한다. 관련 없는 다수의 기존 변경은 보존하고 작업 파일만 커밋한다.

검증 산출물은 기존 artifact-run producer가 작업별 소유권과 로그를 관리한다. 성공 여부와 실제 경로를 완료 시 기록한다.
