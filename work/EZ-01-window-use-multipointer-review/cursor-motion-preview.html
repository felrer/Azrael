Agent는 폭 90% + 흰 윤곽선과 LAIO 팔레트를 채택했습니다. 사용자 커서는 Windows 기본 화살표에 맞춰 윤곽을 다시 따고 같은 입력 기준점에서 비교합니다.

01 / Windows 사용자 커서 정렬 확인

현재 Windows 기본값 aero_arrow.cur · 96 DPI · 32×32 캔버스 · 입력 기준점 (0,0). 픽셀 경계의 잔굴곡을 걷어내고 원래 화살표를 7개의 직선과 둥근 모서리로 정리했습니다. 아래 두 비교는 모두 같은 기준점에 포갭니다.

배경: Windows / 전경: SVG

차이 색상에서 청록은 Windows, 분홍은 SVG, 포개진 부분은 보라로 보입니다. 위 수치는 알파 128 이상 실루엣을 16배 재래스터 후 비교한 결과입니다. 정리 후에는 픽셀 단위 일치보다 원래 기울기와 꼬리 형태를 유지한 직선 윤곽을 우선합니다. 색·안티앨리어싱·그림자 픽셀의 완전 일치는 뜻하지 않습니다. 다른 DPI·접근성 커서 크기는 별도 확인이 필요합니다.

05 / 모션 원칙

전환해도 끝점은 그대로

일반 커서가 흐려지는 동안 같은 끝점에 작은 흰 점이 생기고, 재추적한 사용자 커서로 커집니다. 추종 경로에는 보간을 넣지 않습니다.

즉시 이동, 이전 위치에만 잔상

새 위치의 커서는 애니메이션 없이 즉시 표시합니다. 이전 위치의 몸체만 24% 불투명도로 남아 180ms 동안 제자리에서 사라집니다. 축소·확대·도착 효과·중간 이동 궤적은 없습니다.

쉬고 있을 때는 조용하게

Agent 대기는 불투명도 32%. 사용 종료는 약 220ms 동안 축소하며 사라집니다. 사용자 대기는 저장 아이콘만 표시하며 흰색과 문구는 유지됩니다.

검토용 제안 · HTML / 인라인 SVG / 외부 의존성 없음 · OS 포인터 모양과 동작은 바꾸지 않습니다.
모션 줄이기 환경에서는 자동 재생을 멈추며, 재생 막대로 모든 상태를 확인할 수 있습니다. 배율·색상·시간은 제품 적용 전 조정할 수 있습니다.
