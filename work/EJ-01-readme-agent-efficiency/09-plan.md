## 결과

- 중앙 제목·소개·언어/다운로드/문서 바로가기, 16:9 영상 placeholder, 사용자 중심 4개 기능 요약, 빠른 시작과 피드백 안내를 추가했다. 영상은 준비 중임을 표시하고 재생 링크를 만들지 않았다. `PRODUCT_DEMO` 주석으로 교체 위치를 고정했다.
- 기존 제목과 언어 줄만 새 상단으로 옮겼다. 기존 소개부터 마지막 라이선스까지 `설계와 구현` 아래에 문자 단위로 동일하며 기존 목차도 유지한다. 영어 README는 HEAD와 동일하다.
- Python 검증 exit 0: 문서 보존, 로컬 링크와 앵커(총 109개 링크 참조에서 외부 접속은 제외), SVG XML/title/desc, 영상 placeholder 확인. git diff --check 통과.
- 설치된 markdown-it과 GitHub 유사 기본 CSS로 로컬 렌더했다. 데스크톱 소개·영상·4개 기능 표와 320px 요청 뷰포트에서 상단 줄바꿈을 확인했다. 상단 최대 우측 259px/clientWidth 277px, 로드 실패 이미지 0. 기존 상세 영역의 넓은 표 때문에 미리보기 전체에는 가로 overflow가 있으나 상단 변경은 범위 안에 들어온다. 실제 GitHub 호스팅/테마 픽셀 일치를 주장하지 않는다.
