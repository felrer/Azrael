# README 이미지 안내 문단 삭제

- 승인 범위: 주요 기능 아래의 UI 캡처·합성 데이터·이미지 출처 안내 문단을 한국어와 영어에서 각각 삭제한다. 이미지 파일, 출처 문서와 다른 본문은 유지한다.
- 문서 변경이며 제품·플랫폼 동작은 바꾸지 않는다. Windows에서 정확히 두 문단만 제거됐는지 비교하고 git diff --check를 확인한다. 제품 빌드·실행 테스트는 필요 없다.
- 이 임시 입력은 할당 후 일반 삭제하고 부재를 확인한다. README 두 파일과 이 기록만 작업별 커밋한다.

## 결과

- 한국어·영어 안내 문단을 각각 삭제했다. Python 메모리 비교 exit 0으로 해당 문단과 뒤 빈 줄 외에는 변경되지 않았음을 확인했다.
- git diff --check 통과. 임시 계획 입력의 삭제·부재를 확인했으며 추가 임시 산출물은 없다.
