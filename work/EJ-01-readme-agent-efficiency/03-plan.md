# README 제목 순서

- 승인 범위: 주요 두 파트에 1./2., 각 파트의 하위 제목에 a./b./…를 붙인다. 목차의 레이블과 GitHub 앵커를 함께 갱신하며 두 번째 파트의 기존 하위 제목도 목차에 연결한다.
- 한국어·영어에 같은 번호 체계를 적용한다. 하위의 세부 소제목, 본문, 표, 도식 및 다른 일반 안내 섹션은 유지한다.
- 공통 문서 변경이며 제품·플랫폼 계약은 바뀌지 않는다. Windows에서 두 언어의 번호 대응, 목차 앵커, 본문 보존과 git diff --check를 확인한다. 제품 빌드·브라우저 검증은 필요 없다.
- 임시 입력 .heading-plan-body.md는 할당 후 일반 삭제하고 부재를 확인한다. 이번 파일만 작업별 커밋한다.

## 결과

- 각 README에 주요 파트 1./2., 하위 제목 a.~d./a.~e.를 적용했다. 목차에도 동일하게 표시하고 기존 계정·모델·컨텍스트 압축 하위 제목의 링크를 연결했다.
- Python 메모리 검사 exit 0: 각 언어의 목차 앵커 17개, 2개 주요 제목·9개 하위 제목 순서, 양 언어 대응, 번호를 제외한 본문·표·도식 보존을 확인했다.
- git diff --check 통과. 임시 입력은 일반 삭제 후 부재를 확인했으며 남은 임시 산출물은 없다.
