# 재개 대기 입력 큐잉

요청과 권한: 재개 대기 중 일반 요청이 즉시 전송되는 문제를 수정하고 관련 소스 검증을 수행한다. 설치·배포 제외.
범위: Windows x64/Linux x64/macOS ARM64 공통 웹뷰 정책. 실제 검증은 Windows x64.
설계: waiting/claimed 예약 동안 기본 전송과 로컬·서버 큐 자동 소비를 보류한다. 기존 큐, 명시적 지금 보내기, 비동기 질문 답변의 정책을 보존한다. 예약 종료 뒤 정상 소비를 재사용한다.
소유와 순서: root가 전송 분류 → 자동 소비 가드 → 계약 갱신 → 회귀 검증 → 정리와 작업 커밋을 담당한다. 기존 구현을 확장하며 의존성을 추가하지 않는다.
성공 기준: 기본 입력 큐잉, 예약 유지, 자동 소비 보류/해제, 명시 전송 및 질문·계정 정책 보존. pinned 실제 함수 실행으로 확인한다. 화면 구조·스타일 변화 없음. 설치 앱과 다른 OS 실행은 미검증.
정리: 일회성 파일과 로그는 사용 후 삭제하고 필요한 결과만 이 문서에 보존한다. 동시 변경을 보존한다.
