# 과학자 50명 리소그래프 검토

## 승인과 범위

⑤ 리소그래프 스타일과 기존 품질로 과학자·연구자 50명 이미지 및 인물별 승인 HTML을 만든다. 기존 아인슈타인·퀴리·튜링 3장은 재사용한다. 앱 설치·등록·출시는 포함하지 않는다.

## 구현과 산출물

artifacts/visualizations/scientists-risograph-50/는 사용자에게 전달할 유지 대상이다. images/의 PNG 50장, catalog.json, generation.jsonl, prompts.json, review-template.html과 index.html을 보관한다. 공통 프롬프트와 개별 외형은 재현용 provenance다.

기본 image_gen 도구를 인물별로 호출하고, 승인된 아인슈타인을 스타일 참조로 고정한다. 여섯 요청씩 동시에 생성한다. 결과 복사와 개별 기록을 확인한다. 동일 이미지를 중복 생성하지 않는다.

HTML은 승인/수정 요청/제외/미검토, 메모, 24·32·40·64px 비교, 이전/다음, 검색/상태 필터를 제공한다. 브라우저 자동 저장과 JSON 내보내기/불러오기를 사용하며 외부 전송은 없다. 각 판단을 이미지 SHA-256에 묶어 변경된 이미지에 승인을 승계하지 않는다. 기본은 전원 미검토다.

## 검증과 정리

공통 standalone HTML이며 Windows Chrome에서 실제 조작과 reload 상태 복원을 확인한다. 다른 OS/브라우저 검증은 하지 않는다. 최종 50개 파일 수·PNG 읽기·크기·해시, contact sheet 렌더링과 individual approval/export를 확인한다. renderer 임시 출력은 검토 후 소유 도구로 삭제한다. 요청된 이미지·HTML·메타데이터는 산출물로 유지한다.

## 최종 결과

산출물 준비 완료, 사용자 개별 이미지 검토 대기다. 기존 3장 재사용 + 신규 47장으로 총 50장이다. 전부 고유 SHA-256이며 PNG 헤더와 1254×1254 크기를 확인했다. 이미지 총 154,640,475 bytes, 전체 전달 묶음 154,727,861 bytes다. 생성 도구는 기본 image_gen이며 prompts.json과 catalog.json에 실제 프롬프트를 보관했다.

- 상태 함수의 실제 HTML JavaScript를 추출해 Node vm에서 검사했다. 50명 상태/메모 JSON 왕복, 잘못된 setId·중복 ID·잘못된 상태·초과 길이 메모 거부, 다른 이미지 해시의 미검토 복귀가 통과했다. 실제 exit 0.
- 소유 renderer가 실제 index.html을 3개 PNG 페이지로 렌더링했다. 50명 전부 이미지와 이름을 시각 검토했다. exit 0. Chromium diagnostic 출력의 cp949 reader-thread warning이 있었지만 종료값과 전체 출력 이미지는 확인했다.
- Chrome 도구는 file: URL 방문을 URL policy로 거부했다. 우회하지 않았고 빈 탭을 닫았다. 실제 브라우저 클릭·다운로드·가져오기 UI 검증은 미수행이다. 제한을 사용자에게 알렸다.
- 우젠슝 이미지 생성 후 원본 복사는 성공했지만 동시 generation.jsonl append가 잠겨 기록이 실패했다. 생성 작업 종료 후 복사본과 정확히 같은 SHA-256의 원본을 확인해 해당 기록만 순차 복구했다. 재생성하지 않았다.
- renderer가 만든 temporary preview directory를 소유 cleanup 명령으로 삭제하고 exists:false를 확인했다. 남은 사용자 확인용 백업이나 일회성 파일은 없다.
- HTML·이미지·catalog·프롬프트·생성 기록·검증 결과·README는 사용자 요청 산출물로 유지한다. 앱 소스와 설치 상태는 변경하지 않았다.

사용자는 index.html을 열고 한 명씩 판단한 뒤 검토 결과 JSON을 전달한다. HTML의 클릭은 채팅이나 앱에 자동 전송되지 않는다. 앱 등록은 별도 작업이다.

## 판단 후 자동 이동

승인·수정 요청·제외는 현재 인물의 상태를 저장한 뒤 다음 인물로 이동한다. 마지막 인물에서는 위치를 유지하고 JSON 저장 안내를 표시한다. 미검토 버튼은 이동하지 않는다. 메모는 판단 전에 입력하거나 이전 버튼으로 돌아와 수정한다. 기존 이미지 해시·storage key·이전 승인 결과를 유지한다.

현재 HTML과 유지보수 template의 실제 chooseStatus 함수를 추출해 각각 24개 경우를 검증했다. 판단 4종 × 첫/끝 직전/마지막 위치 × 로컬 저장 성공/실패 조건에서 저장이 이동보다 먼저 호출되는지, 메모 보존, 마지막 범위 제한, 저장 실패 안내 보존을 확인했다. 총 48개 경우 통과, actual exit 0. 레이아웃·이미지는 변경하지 않았으며 이전 렌더링 증거를 재사용한다. 실제 브라우저 클릭 검증은 기존 file: URL 정책 제한으로 미수행이다. 새 임시 파일은 만들지 않았다.
