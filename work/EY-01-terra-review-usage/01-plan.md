상태: 소스 변경·Windows x64 검증 완료. 전체 앱 빌드·설치 미수행; 사용자 추가 결정 없음.

## 목표와 권한
Terra의 공식 API 환산 요금을 추가하고 자동 검토는 무료 정책에 따라 건수로 표시한다. 기존 Terra 미산정 기록은 소급 재계산하지 않는다. 소스 수정·검증·정리·작업 커밋 범위이며 전체 앱 빌드, 설치, 게시와 원격 push는 포함하지 않는다.

## 구현과 보존
- 기존 요금 계산기에 `gpt-6.1-terra`의 정확한 모델 ID, 표준·272K 초과 구간과 Fast/Flex/Batch 요금을 추가했다. 출처와 확인일은 요금표에 둔다. 확인되지 않은 Ultrafast는 미산정을 유지한다.
- `openai` / `codex-auto-review`만 기존 미산정 건수를 횟수로 표시하고 프로젝트·달력의 미산정 경고에서 제외한다. 다른 공급자의 동일 모델명과 다른 미산정 모델은 기존 의미를 유지한다. 저장 데이터는 변경하지 않는다. 무료 처리는 사용자 정책이며 계정별 실제 청구 검증은 아니다.
- 설계 소유자는 [프로젝트 사용량](../../docs/architecture/project-usage.md)이다. 기존 `ui.account-settings`의 소유 파일과 `test-usage-window-ui.cjs` 실행기에 프로젝트 사용량을 연결했다.

## 검증과 범위
공통 동작으로 Windows x64, Linux x64, macOS ARM64에 적용한다. 실제 검증은 Windows x64에서 수행했다.

| 검사 | 결과 |
| --- | --- |
| 정확한 요금 계산 모듈·요금표를 고정한 격리 Rust crate | 10개 통과, 종료 0 |
| 기존 공통 사용량 UI 실행기 | 47개 통과, 종료 0 |
| TypeScript `--noEmit --incremental false` | 종료 0 |
| 실제 생산 HTML/CSS의 격리 Chrome 화면 | 밝은/어두운 테마 × 420/655px, hover·키보드·금액·횟수·경고·경계 25개 항목 통과, 종료 0 |
| 화면 직접 확인 | `light-655.png`, `dark-420.png` 확인 완료 |
| 변경 기능의 보존 목록 검사 | 해당 기능의 소유 파일·명령 검사 통과 |

Rust fixture는 생산 `TokenUsage` 선언의 필드를 추출하고 직렬화 속성만 제외한다. 전체 core 통합 컴파일, 실제 공급자 청구, 패키지·설치 호스트와 Linux/macOS 실행의 검증을 뜻하지 않는다. 보존 목록 전체 검사에는 다른 작업의 `tool.project-maintenance` 중복 owner 및 기존 directory owner와 현재 검사기 간 불일치가 있어 수정하지 않았다. 이번 변경 기능의 검사는 따로 통과했다.

테스트 유지 이유는 향후 요금표·집계 편집에서 구간/등급을 누락하거나 모델 예외를 다른 공급자에 적용하는 반복 실수를 탐지하는 것이다. 새 테스트 파일은 추가하지 않았다.

## 실행과 재시도
요금 계산 준비·실행은 2026-11-02 22:12 KST에 시작해 약 75초 걸렸다. 그동안 독립적인 화면 검증을 준비했다. 첫 화면 시도는 PowerShell stdin 인코딩이 기대 문자열의 특수문자를 바꿔 실패했고, 두 번째는 브라우저 탐색 응답 시간 초과로 실패했다. 소스 입력을 바꾸지 않고 Unicode escape와 직접 document 설정으로 검증 fixture를 고친 세 번째 시도가 통과했다. 실패 결과는 성공으로 변경하지 않았다. 첫 시도의 브라우저 종료 확인 실패는 tracked close와 독립 CIM 관측으로 확인한 뒤 owner를 통해 실패 상태로 닫았다.

[검증 요약](03-verification.json)은 소스 해시·실제 종료 코드·검사 범위·재시도를 독립적으로 보존한다. [종료 근거](02-render-stop-evidence.json)는 첫 화면 시도의 종료와 실패 결과를 보존한다. 자세한 임시 로그·스크린샷·컴파일/브라우저 fixture는 이 요약 확보와 화면 확인을 끝냈으므로 정리 대상이다.

## 정리와 커밋
검증 실행기 소유의 5개 run은 현재 보호·참조 검토 후 명시적으로 삭제했고 실제 경로 부재를 확인했다. [정리 영수증](04-cleanup.json)은 등록 기준 논리 크기 127,783,766바이트와 항목별 삭제 결과를 보존한다. 브라우저·컴파일·로그·스크린샷 잔여물은 없다. 다른 작업의 수정과 이미 stage된 변경을 보존하기 위해 이번 작업만 별도 Git index로 커밋한다. 일시 index와 transaction control 파일도 작업 소유 정리 대상이며, Git 커밋이 참조를 해제한 뒤 같은 검토·삭제 절차를 적용한다. 커밋 identity는 Git 이력과 최종 응답이 소유한다.
