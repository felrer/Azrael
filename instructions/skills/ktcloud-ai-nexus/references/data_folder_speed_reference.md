# 세션 로컬 디스크와 데이터 폴더 속도 참고

이 문서는 AI Nexus 세션에서 작업 위치를 선택할 때 참고하는 공통 운영 기준입니다.

## 측정 요약

측정일: 2026-08-18

- 세션 로컬 디스크: `/home/work` (ext4)
- 영속 데이터 폴더: `/home/work/<persistent-folder>` (NFS)
- 512MiB 순차 읽기: 로컬 약 4.0GiB/s, NFS 약 3.3GiB/s
- 512MiB 순차 쓰기: 로컬 약 648MiB/s, NFS 약 965MiB/s
- 64KiB 파일 500개 쓰기: 로컬 약 2,018 files/s, NFS 약 482 files/s

대용량 순차 I/O는 NFS도 충분히 빠르지만, 작은 파일을 많이 생성·수정하는 작업은 로컬 디스크가 약 4배 빠릅니다. 측정값은 세션·캐시·부하에 따라 달라질 수 있으므로 절대 성능 보장값으로 사용하지 않습니다.

## 공통 운영 원칙

- 자주 수정하는 소스, 임시 파일, 빌드 산출물은 `/home/work`에서 작업합니다.
- 데이터셋, 최종 모델, checkpoint, 로그와 결과물은 `/home/work/<persistent-folder>` 아래에 보관합니다.
- `/home/work`의 파일은 세션 종료 시 사라질 수 있으므로, 기능 단위 완료 시점과 세션 종료 전에 영속 폴더로 복사합니다.
- 유일한 사본을 이동하지 말고 복사·동기화합니다.
- 대용량 데이터셋은 먼저 NFS에서 사용하고, DataLoader가 병목일 때만 로컬로 한 번 staging합니다.
- 장시간 학습 전에는 새 세션에서 간단한 I/O 측정을 다시 수행합니다.
